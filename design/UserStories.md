# Requirements

## User Stories

- As a user, I want to create a customer with a name and email to be able to reference it.
- As a user, I want to get a customer by its id to be able to see its name and email.
- As a user, I want to update a customer by its id to be able to change its name or email.
- As a user, I want to delete a customer by its id to be able to remove it from the system.
- As an admin, I want to add available credit to a customer to be able to change its credit.
- As an admin, I want to list all the customers sorted by credit to be able to see all the customers in the system.
